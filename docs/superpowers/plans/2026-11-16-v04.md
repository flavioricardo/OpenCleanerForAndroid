# OpenCleaner 0.4 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** add old WhatsApp media, old files, a folder size view, the Android trash and sensitive-access apps, without Shizuku.

**Architecture:** `scan/` gains the new kinds, the folder tree and the trash finding, all pure and tested on the JVM. `system/` reads MediaStore (trash) and package permissions. `ui/` gets the Storage page and the new groups and sections.

**Tech Stack:** Kotlin 2.1, Compose BOM 2024.12.01, JUnit 4. Build in CI only.

**Spec:** `docs/superpowers/specs/2026-11-16-v04-design.md`.

## Global Constraints

- No new dependency; no INTERNET permission; minSdk 30.
- Every new cleanup item starts unchecked.
- Protected folders hold for every item.
- Strings exist in EN and PT-BR.

## Review Focus

- A WhatsApp video older than N months and over 100 MB: listed once, under old videos, never also under large videos.
- Files the trash renamed (`.trashed-*`): never listed again as old media.
- Trash on, but the user cancels the system dialog: the files stay, and the result shows a warning.
- WhatsApp Business folders ("WhatsApp Business Video"): handled like WhatsApp.
- No usage access: no privacy section, no crash.

### Task 1: scan

- `ScanOptions.oldMonths` (default 6).
- `Kind.WA_OLD_VIDEOS`, `WA_OLD_IMAGES`, `WA_OLD_AUDIO`, `WA_OLD_DOCS`, `OLD_DOWNLOADS`, `OLD_SCREENSHOTS`, `OLD_RECORDINGS`, `TRASH`, `PRIVACY_APP`.
- `AppInfo.sensitive: Set<Sensitive>`; `Trashed(uri, bytes)`; `Action.EmptyTrash(uris)`.
- `scan(...): Scan(findings, tree: DirNode?, biggest)`; `analyze()` returns `scan().findings`.
- Tests:
  - `oldMedia_byTypeAndAge`: covers Business and hidden `.trashed-` files; no double count with large videos.
  - `oldFiles_downloadsScreenshotsRecordings`.
  - `trash_finding`.
  - `privacy_apps`.
  - `tree_sumsAndBiggest`.

### Task 2: system

- `loadApps` reads `GET_PERMISSIONS` into `sensitive`.
- `Trash.kt`:
  - `loadTrash(ctx): List<Trashed>`;
  - `mediaUris(ctx, files): Map<File, Uri>`;
  - `trashRequests(ctx, uris)` and `deleteRequests(ctx, uris)`, in batches of 500.

### Task 3: ui

- Storage page.
- New groups in Cleanup, with the WhatsApp strip.
- Privacy section in Apps.
- Options: old months and the trash switch.
- Cleaning: trash step and the EmptyTrash action.
- Version 0.4.0.
- CI green, code review, fixes, PR, release.
