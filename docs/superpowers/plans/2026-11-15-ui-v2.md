# UI v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the single-list UI with the desktop-like three-tab UI, with step-by-step progress and a per-category result.

**Architecture:** `scan/` keeps its logic and gains progress callbacks (default no-op). `ui/` is rewritten: `App.kt` (state, analysis and cleaning flows), `Pages.kt` (Health, Clean, Apps, Detail, Welcome), `Steps.kt` (progress and result), `Icons.kt` (Lucide path data), `Theme.kt`.

**Tech Stack:** Kotlin 2.1, Compose BOM 2024.12.01, Material 3, JUnit 4. Build only in CI.

**Spec:** `docs/superpowers/specs/2026-11-15-ui-v2-design.md` (and the v1 spec).

## Global Constraints

- No new dependency; no INTERNET permission; minSdk 30.
- Every user-facing string in `values/strings.xml` (EN) and `values-pt-rBR/strings.xml`.
- Analysis never deletes; deletion only after "Limpar"; system dialogs never bypassed.
- Lucide icons only, from lucide-static 1.58.0, with the ISC notice in `Icons.kt`.

## Review Focus

- Analysis with no permissions: tabs still render, cards say what is missing.
- User cancels the cache or uninstall dialog: the result marks it with a warning, flow goes on.
- Unchecking every file of an item in Detail: the item frees 0 and is not counted as selected bytes.
- Rotation or dark mode during a step: no crash (activity keeps `configChanges`).
- An app uninstalled between analysis and cleaning: the uninstall step ends with a warning, not a crash.
